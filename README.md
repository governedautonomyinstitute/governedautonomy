# Governed Autonomy Doctrine — public mirror

**Canonical site: https://governedautonomy.org/ (always authoritative).** This repository mirrors the doctrine's text so it can be cited, linked, diffed, and discussed. Current version: **v3.4**. Version history: [changelog](changelog.md).

The Governed Autonomy Doctrine is the architectural standard for governing autonomous AI agents as first-class enterprise identities, through continuous runtime enforcement, across every system they touch — at the level of behavior, not just access. Its proposed Conformance Layer ([RFC 001](rfc-001-conformance-layer.md), open for comment through **October 31, 2026**) defines twenty-nine testable criteria an implementation can be assessed against, and can fail.
